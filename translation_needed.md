## 📋 How to Add Translations

Once you have a translation, add it to `kaubru-backend/seed.py` in the `WORDS` list:

```python
{"english": "village", "kaubru": "YOUR_TRANSLATION", "category": "places",
 "example_english": "I live in a village.", "example_kaubru": "YOUR_KAUBRU_SENTENCE"},
```

Then run from the `kaubru-backend/` folder:
```
python seed.py
```

The new words will be added automatically without affecting existing data.
